# AI Use Declaration

## Project
StyleMatch AI — Football Playstyle Similarity and Recruitment Support System

## AI Tools Used
ChatGPT was used as a development-support tool during this project.

It assisted with:

- brainstorming the system architecture;
- structuring the data-cleaning pipeline;
- suggesting Python implementation patterns;
- debugging Python, VS Code and Streamlit issues;
- structuring the K-Means clustering workflow;
- improving documentation and presentation structure;
- reviewing ethical considerations and limitations.

## How AI Output Was Verified

AI-generated suggestions were not accepted automatically.

The team:

- reviewed generated code before using it;
- executed and tested the code locally;
- corrected syntax and runtime errors;
- checked outputs against the actual football dataset;
- verified that the clustering results were reproducible;
- evaluated candidate K values using multiple clustering metrics;
- tested the player-similarity system;
- verified that StyleMatch AI questions are dynamically generated from the real model outputs;
- modified generated suggestions to match the project requirements and architecture.

## Example Prompt Categories

Examples of prompts used include:

- Help design a reproducible football-player data-cleaning pipeline.
- Help structure K-Means clustering for position-aware football analysis.
- Explain how to evaluate candidate values of K.
- Help debug development and deployment issues.
- Help structure the GitHub documentation.

## Human Responsibility

The final design, implementation, testing, evaluation and interpretation decisions remained the responsibility of the student team.

AI tools were used to support development rather than replace understanding, testing or critical evaluation.
